# Avoid

네트워크프로그래밍 텀프로젝트 (9조): 1인용 피하기 게임을 java.net 소켓 기반 1:1 실시간 대전 게임으로 확장하고 채팅을 결합한다.

## 원본 소스

- [Roronoawjd/Ddong_avoid_game](https://github.com/Roronoawjd/Ddong_avoid_game) (Java Swing 똥 피하기 게임)
- 첫 커밋은 원본 코드를 수정 없이 가져온 상태이며, 이후 커밋부터 팀이 수정·추가한 내용이다.

## 실행 방법 (Eclipse)

1. File > Import > Existing Projects into Workspace 에서 이 폴더를 선택한다.
2. `src/Ddong/Main.java` 를 실행한다. (이미지는 `src/images/` 에서 읽는다)
